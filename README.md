# 도시 폐기물 통계 시뮬레이션

임시 CSV 생성용 합성 데이터 시뮬레이션입니다.

- 단위: kg/일
- 기준: 환경부 제6차 전국폐기물통계조사 생활폐기물 1인당 0.9506kg/일을 주거 시설 기준값으로 사용
- 계산: 거주 인구와 종사 인구 × 업종별 1인 1일 생활폐기물 계수 + 유동 인구 × 방문 배출계수 + 건설·의료·사업장 특수 폐기물 보정
- 설정: 건물 개수, 인구 기준 배율, 건물 유형 비율을 조정하면서 재구성 전 예상 거주/종사/유동 인구를 확인할 수 있음
- 프리셋: 빌라/저층 주거지, 아파트 단지, 원도심/상가 밀집지, 업무지구, 공장지대, 복합 생활권 유형을 선택할 수 있음
- 도시 데이터 입력: 목표 거주 인구, 선택적 종사/유동 인구, 목표 폐기물 톤/일을 넣어 인구·폐기물 배율을 자동 계산할 수 있음
- 인구 보정: 화면에 배치된 건물은 실제 건물/블록을 대표하며, 재구성 후 거주/종사/유동 인구 합계가 설정창 예상치와 맞도록 보정됨
- 도로/교통: 도로는 왕복 2차선으로 표시되며, 자동차 수는 거주·종사·유동 인구 규모에 비례해 자동 산정됨
- CSV/툴팁: 종량제봉투 대상 폐기물, 음식물류 폐기물, 재활용가능자원, 대형폐기물 등 배출 카테고리와 비닐류, 음식물쓰레기, 건설폐기물 등 세부 폐기물로 분해하여 표시/내보냄

정책·시설 설계용 정밀 예측이 아니라, 알고리즘 수업/프로토타입에서 현실적인 크기의 임시 입력 데이터로 쓰기 위한 모델입니다.

## 자료구조와 알고리즘

시뮬레이션 내부는 컴퓨터공학에서 배우는 기본 자료구조와 알고리즘을 중심으로 구성했습니다. 계산식과 결과의 의미는 유지하면서, 건물 배치와 폐기물 집계를 설명하기 쉬운 구조로 정리했습니다.

- 배열: 건물 유형, 폐기물 종류, 폐기물 카테고리의 키 목록을 고정 배열로 관리해 툴팁, CSV, 집계 순서를 일정하게 유지합니다.
- 해시 테이블: 건물 유형별 통계와 폐기물 종류별 합계를 객체 기반 테이블에 누적합니다.
- 누적합 배열: 건물 유형 비율을 누적합으로 변환해 가중 랜덤 선택에 사용합니다.
- 이진 탐색: 누적합 배열에서 난수가 들어갈 위치를 찾아 건물 유형을 선택합니다.
- 함수 테이블: 도로 레이아웃 번호를 배열 인덱스로 사용해 해당 도로 생성 함수를 선택합니다.
- 기하 알고리즘: 점과 선분 사이 최단 거리를 계산해 건물이 도로와 너무 가까운지 검사합니다.
- 충돌 검사: 새 건물 후보가 도로 또는 기존 건물과 겹치는지 순차 탐색과 조기 종료로 확인합니다.
- 비례 스케일링: 실제 배치된 건물의 인구 합계가 설정 목표에 가까워지도록 비율을 유지하며 보정합니다.

주요 복잡도는 건물 수를 `n`, 도로 수를 `r`, 건물 유형 수를 `k`, 폐기물 종류 수를 `m`이라고 할 때 다음과 같습니다.

| 기능 | 사용 알고리즘 | 시간 복잡도 |
|---|---|---:|
| 건물 유형 선택 | 누적합 + 이진 탐색 | `O(log k)` |
| 건물 후보 충돌 검사 | 도로/건물 순차 탐색 | `O(r + n)` |
| 인구 보정 | 비례 스케일링 | `O(n)` |
| 도시 통계 집계 | 해시 테이블 누적 | `O(n + m)` |
| 폐기물 세부 배분 | 비율 기반 분배 | `O(m)` |
