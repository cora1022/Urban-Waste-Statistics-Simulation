## プロジェクトの背景

このリポジトリは、アルゴリズムを応用して社会問題に取り組む個人課題として始まりました。公開されている廃棄物データを調べる中で、市・郡単位の総量は確認できましたが、住宅、店舗、学校、工場のようにその数値を生み出す小さな単位を推定することは困難でした。

そこで、建物種類ごとに人口と廃棄物発生ルールを定義しました。小さな生活圏から大都市まで、ユーザーが入力した条件に応じて公式統計に近い規模の合成データを生成します。都市AとBの規模が大きく異なる場合でも総量だけを比較せず、居住・就業・流動人口、施設構成、1人当たりの廃棄物発生量をまとめて分析することがこのプロジェクトの中心です。

企画の背景と実装過程は、[実際の統計に近い廃棄物都市を作る](https://cora1022.com/blog/posts/urban-waste-statistics-simulation.html)にまとめています。

## 主な機能

- 初回表示時に単一都市モードまたは2都市比較モードを選択してシミュレーションを開始
- 韓国語、英語、日本語、中国語（簡体字）を即時に切り替え、選択した言語を保存
- 単一都市モードで1つの都市を全画面表示し、単独の統計をエクスポート
- 都市AとBの居住・就業・流動人口と1日当たりの廃棄物発生量を比較
- 低層住宅地、集合住宅、旧市街、業務地区、工業地帯、複合生活圏のプリセット
- 目標人口と目標廃棄物量（トン/日）から人口・廃棄物倍率を自動計算
- 建物数、建物種類の重み、道路構造、自動車比率、廃棄物発生比率を調整
- 従量制ごみ、食品廃棄物、再資源化物、大型・建設・医療・事業系廃棄物を集計
- 建物ごとのツールチップと、種類・廃棄物・人口・名称順のCSV統計ダウンロード

## 韓国統計の反映

建物種類ごとの排出係数と構成比は、**2023年全国廃棄物発生・処理現況**の一般廃棄物 `1.2 kg/日・人` と、韓国環境部の **第6次全国廃棄物統計調査** を比較基準として補正しました。第6次調査の1人当たり一般廃棄物 `950.6 g/日` のうち、従量制ごみ `330.8 g`、食品廃棄物 `310.9 g`、再資源化物 `308.8 g` の割合を詳細構成比の基準として使用しています。

公式数値をすべての建物に同じように掛けるわけではありません。建物種類ごとに常住人口と訪問人口の排出係数を変え、建設・医療・事業系の特殊廃棄物を追加します。その後、都市全体の結果が韓国の一般廃棄物統計と近い規模・分布になるよう係数を補正しています。

- 出典：[韓国環境部 第6次全国廃棄物統計調査結果](https://mcee.go.kr/home/web/board/read.do?boardId=1597240&boardMasterId=939&menuId=10598)

## 計算方法

各建物に居住人口、就業人口、流動人口と建物種類別の係数を適用し、1日当たりの廃棄物発生量を計算します。

```text
一般廃棄物 = （居住人口 + 就業人口）× 常住人口排出係数
             + 流動人口 × 訪問人口排出係数

特殊廃棄物 = 常住人口 × 業種別係数
             + 流動人口 × 業種別係数
             + 建物面積 × 面積係数

総廃棄物 = 一般廃棄物 × 日次変動係数
           + 特殊廃棄物 × 特殊変動係数
```

計算結果は建物種類別の構成比に基づいて16種類の詳細廃棄物へ配分し、その後7つの排出カテゴリーに再集計します。設定で入力した目標人口と目標廃棄物量は、基準推定値との比率を計算して各倍率へ反映します。

## データ構造とアルゴリズム

- **配列**：建物種類、廃棄物種類、カテゴリーの基準順序を維持します。
- **ハッシュテーブル**：建物種類別統計と廃棄物種類別合計をオブジェクトへ累積します。
- **累積和と二分探索**：建物種類の重みから累積和を作り、乱数が含まれる区間を二分探索で選択します。
- **関数テーブル**：道路レイアウト番号をインデックスとして、7種類の道路生成関数から1つを選択します。
- **幾何アルゴリズム**：点と線分の最短距離を求め、建物と道路の重なりを防ぎます。
- **衝突判定**：新しい建物候補と既存建物の中心距離および間隔を順番に検査します。
- **比例スケーリング**：建物間の人口比率を維持しながら、配置された建物の人口合計を目標値に合わせます。
- **比率ベースの分配**：一般・特殊廃棄物を建物種類別の構成比に従って詳細廃棄物へ分配します。

建物数を `n`、道路数を `r`、建物種類数を `k`、廃棄物種類数を `m` とした場合、主な時間計算量は次のとおりです。

| 機能 | 使用アルゴリズム | 時間計算量 |
|---|---|---:|
| 建物種類の選択 | 累積和 + 二分探索 | `O(log k)` |
| 建物候補の衝突判定 | 道路・建物の順次探索 | `O(r + n)` |
| 人口補正 | 比例スケーリング | `O(n)` |
| 都市統計の集計 | ハッシュテーブルへの累積 | `O(n + m)` |
| 廃棄物の詳細分配 | 比率ベースの分配 | `O(m)` |
