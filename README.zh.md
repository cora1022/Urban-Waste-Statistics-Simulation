- 在线模拟：[cora1022.com/Urban-Waste-Statistics-Simulation](https://cora1022.com/Urban-Waste-Statistics-Simulation/)

## 项目背景

本仓库最初是一个运用算法处理社会问题的个人课题。在调查公开废弃物数据时，可以找到市、郡级别的总量，但很难推断构成这些数值的住宅、商店、学校和工厂等更小单位。

因此，我为不同建筑类型定义了人口和废弃物产生规则。模拟器会根据用户输入的条件，从小型生活区到大型城市生成规模接近官方统计的合成数据。即使城市A与城市B的规模差异很大，也不会只比较总量，而是综合分析居住、就业、流动人口、设施构成和人均废弃物产生量。

项目规划背景与实现过程记录在[创建接近真实统计的废弃物城市](https://cora1022.com/blog/posts/urban-waste-statistics-simulation.html)中。

## 主要功能

- 首次进入时选择单城市模式或双城市对比模式并开始模拟
- 在韩语、英语、日语和简体中文之间即时切换并保存所选语言
- 在单城市模式下全屏模拟一座城市并单独导出统计数据
- 比较城市A与城市B的居住、就业、流动人口和每日废弃物产生量
- 提供低层住宅区、公寓社区、老城区、商务区、工业区和混合生活区预设
- 根据目标人口和目标废弃物吨/日自动计算人口与废弃物倍率
- 调整建筑数量、建筑类型权重、道路结构、车辆比例和废弃物产生比例
- 汇总计量收费垃圾、厨余垃圾、可回收物、大件、建筑、医疗和商业废弃物
- 提供单栋建筑提示信息，并按类型、废弃物、人口或名称排序下载CSV统计

## 韩国统计数据的应用

建筑类型的排放系数和构成比例以 **2023年全国废弃物产生与处理现状** 中的生活废弃物 `1.2 kg/日·人`，以及韩国环境部 **第6次全国废弃物统计调查** 为校准基准。第6次调查的人均生活废弃物为 `950.6 g/日`，其中计量收费垃圾 `330.8 g`、厨余垃圾 `310.9 g`、可回收物 `308.8 g`，这些比例被用作详细构成的参考。

官方数值不会对所有建筑统一相乘。不同建筑类型使用不同的常住人口和访问人口排放系数，并另外加入建筑、医疗和商业特殊废弃物。之后再校准系数，使整座城市的结果在规模与分布上接近韩国生活废弃物统计。

- 来源：[韩国环境部第6次全国废弃物统计调查结果](https://mcee.go.kr/home/web/board/read.do?boardId=1597240&boardMasterId=939&menuId=10598)

## 计算方式

每栋建筑都会应用居住人口、就业人口、流动人口和建筑类型系数，计算每日废弃物产生量。

```text
生活废弃物 = （居住人口 + 就业人口）× 常住人口排放系数
             + 流动人口 × 访问人口排放系数

特殊废弃物 = 常住人口 × 行业系数
             + 流动人口 × 行业系数
             + 建筑面积 × 面积系数

废弃物总量 = 生活废弃物 × 每日波动系数
             + 特殊废弃物 × 特殊波动系数
```

计算结果先按照各建筑类型的构成比例分配到16种详细废弃物，再汇总为7个排放类别。设置中输入的目标人口和目标废弃物量会与基准估算值计算比例，并反映到相应倍率中。

## 数据结构与算法

- **数组**：保持建筑类型、废弃物种类和类别的基准顺序。
- **哈希表**：在对象中累计建筑类型统计和各废弃物种类总量。
- **前缀和与二分查找**：根据建筑类型权重构建前缀和，并通过二分查找选择随机数所在区间。
- **函数表**：将道路布局编号作为索引，从7种道路生成函数中选择一种。
- **几何算法**：计算点与线段之间的最短距离，防止建筑与道路重叠。
- **碰撞检测**：依次检查新建筑候选与现有建筑之间的中心距离和间距。
- **比例缩放**：在保持建筑间人口比例的同时，使建筑人口总和符合目标值。
- **按比例分配**：按照建筑类型构成比例，将生活与特殊废弃物分配到详细种类。

设建筑数量为 `n`、道路数量为 `r`、建筑类型数量为 `k`、废弃物种类数量为 `m`，主要时间复杂度如下：

| 功能 | 使用算法 | 时间复杂度 |
|---|---|---:|
| 建筑类型选择 | 前缀和 + 二分查找 | `O(log k)` |
| 建筑候选碰撞检测 | 依次遍历道路与建筑 | `O(r + n)` |
| 人口校准 | 比例缩放 | `O(n)` |
| 城市统计汇总 | 哈希表累计 | `O(n + m)` |
| 详细废弃物分配 | 按比例分配 | `O(m)` |
